# RISC-V Operating System Kernel

A university project developed as part of the Operating Systems course at the University of Belgrade, School of Electrical Engineering.

The project focuses on implementing core operating system functionalities for the RISC-V architecture using C++ and assembly.

## Key Features

- Thread creation and context switching
- Thread scheduling
- Semaphores and synchronization
- System calls and trap handling
- Dynamic memory management
- Thread sleeping and joining
- User and kernel mode separation

## Technologies

- C / C++
- RISC-V Assembly
- QEMU Emulator
- Linux
- GCC Toolchain

## Project Overview

The project provided hands-on experience with low-level systems programming, concurrency, memory management, and operating system design.
